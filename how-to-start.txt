Sprint 2 - full Docker setup (recommended)

Prerequisite: Docker Desktop running with Linux containers.
From the extracted repository root, copy the example settings if there is no
DMS/.env yet (do not overwrite an existing configuration):

Copy-Item DMS/.env.example DMS/.env
 docker compose -f DMS/docker-compose.yml build
 docker compose -f DMS/docker-compose.yml up -d --wait

On Linux/macOS use: cp DMS/.env.example DMS/.env
Wait for Keycloak startup: docker compose -f DMS/docker-compose.yml logs keycloak

Frontend: http://localhost/ (Log in with student / student)
API health: http://localhost:8081/health
Keycloak admin: http://localhost:8082/admin/ (admin / admin with example settings)

Use Upload to add a PDF, Documents to see the dashboard, and a filename to
open details. Requests pass through nginx to the backend. Database migrations
run automatically. The API does not yet validate access tokens (#36, Sprint 3).

Stop without deleting stored data:
docker compose -f DMS/docker-compose.yml stop

Local frontend development (optional)

Requires Node.js 24.x and npm. From the repository root:
docker compose -f DMS/docker-compose.yml up -d --build --wait dms-api keycloak
Set-Location DMS/frontend
npm ci
npm start

Frontend: http://localhost:4200/ (student / student)
The development server forwards /api requests to localhost:8081.
Stop the frontend with Ctrl+C.

Local backend development and Swagger (optional)

Requires the .NET 10 SDK. From the repository root:
docker compose -f DMS/docker-compose.yml stop dms-api
docker compose -f DMS/docker-compose.yml up -d --wait postgres keycloak
dotnet run --project DMS/src/DMS.API --launch-profile http --urls http://localhost:8081

The local API defaults to database/user/password dms. If your DMS/.env differs,
set ConnectionStrings__Postgres accordingly; dotnet run does not load .env.
Swagger: http://localhost:8081/swagger (Development environment only).

Tests (from repository root):
dotnet test DMS/src/DMS.UnitTests/DMS.UnitTests.csproj
Set-Location DMS/frontend
npm ci
npm test -- --watch=false
